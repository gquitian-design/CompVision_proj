# 15-Layer CNN for Skin Condition Classification (35 Classes)

This project implements a custom 15-layer Convolutional Neural Network (CNN) specifically tailored for dermatological image classification. It identifies 35 distinct categories: **34 pathological skin conditions** and **1 healthy skin control**.

---

## 1. Model Architecture

The network follows a repetitive pattern of **2 convolutional layers followed by 1 downsampling layer** across 4 feature extraction blocks (12 operational layers), followed by a 3-layer fully connected classification head (15 operational layers total).

| Block / Stage | Layers | Operations | Output Size ($224 \times 224$ input) |
|---|---|---|---|
| **Block 1** | Layer 1, 2, 3 | Conv2D ($32$) $\rightarrow$ Conv2D ($32$) $\rightarrow$ MaxPool ($2 \times 2$) | $112 \times 112 \times 32$ |
| **Block 2** | Layer 4, 5, 6 | Conv2D ($64$) $\rightarrow$ Conv2D ($64$) $\rightarrow$ MaxPool ($2 \times 2$) | $56 \times 56 \times 64$ |
| **Block 3** | Layer 7, 8, 9 | Conv2D ($128$) $\rightarrow$ Conv2D ($128$) $\rightarrow$ MaxPool ($2 \times 2$) | $28 \times 28 \times 128$ |
| **Block 4** | Layer 10, 11, 12 | Conv2D ($256$) $\rightarrow$ Conv2D ($256$) $\rightarrow$ MaxPool ($2 \times 2$) | $14 \times 14 \times 256$ |
| **Adapter** | — | Adaptive Average Pooling | $2 \times 2 \times 256$ ($1,024$ flattened) |
| **Classifier** | Layer 13 | Dense ($1024 \rightarrow 512$) + BatchNorm + ReLU + Dropout ($p=0.4$) | $512$ |
| | Layer 14 | Dense ($512 \rightarrow 256$) + BatchNorm + ReLU + Dropout ($p=0.3$) | $256$ |
| | Layer 15 | Dense ($256 \rightarrow 35$) **Output Logits** | $35$ |

## 3. Getting Started

### Environment Setup
Activate your virtual environment:
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### Dataset Organization (Option 1: CSV Manifest)
1. Place your 35 category subfolders directly inside `data/`:
```text
data/
├── Acne And Rosacea Photos/
│   └── ...
├── Healthy/
│   └── ...
└── ... (all 35 categories)
```
2. Place `balanced_dataset.csv` in the project root directory.

3. Run the preprocessor:
```bash
python preprocess.py
```
This generates `preprocessed/train.csv`, `val.csv`, and `test.csv` using Stratified Group K-Fold to prevent patient/image leakage.

## 4. Usage

### Verify the Model Architecture
```bash
python src/model.py
```

### Train the Network
```bash
python src/train.py --epochs 40 --batch_size 32 --lr 0.001
```

**Key training options:**
- `--epochs`: Total training epochs (default: `40`).
- `--batch_size`: Batch size (default: `32`).
- `--lr`: Initial learning rate for AdamW (default: `0.001`).
- `--use_class_weights`: Automatically applies inverse-frequency weighting to address 35-class imbalance.
- `--checkpoint_dir`: Target folder for `best_model.pth` and `training_history.json`.

Hardware acceleration is detected automatically:
- **Apple Silicon (Mac)**: Uses Metal Performance Shaders (`mps`).
- **NVIDIA GPU**: Uses CUDA (`cuda`).
- **CPU**: Default fallback.

### Evaluate on Test Set
```bash
python src/evaluate.py --checkpoint checkpoints/best_model.pth
```
This generates:
1. **Top-1 Accuracy**: Exact class match.
2. **Top-3 Accuracy**: Differential diagnosis evaluation.
3. **Full Classification Report**: Precision, Recall, and F1-score for each of the 35 classes.
4. **Normalized Confusion Matrix**: Saved as `checkpoints/confusion_matrix.png`.

### Plot Learning Curves
```bash
python src/plot_results.py --history checkpoints/training_history.json
```
Generates publication-quality Train vs. Val Loss and Top-1/Top-3 Accuracy curves saved to `checkpoints/learning_curves.png`.

### Single-Image Prediction & Differential Diagnosis
```bash
python src/predict.py --image path/to/sample.jpg --checkpoint checkpoints/best_model.pth --cam
```
Outputs:
- Top-3 differential diagnosis conditions with confidence percentages.
- Healthy vs. Pathological classification.
- Saves the Grad-CAM visual heatmap overlay.

### Saliency Heatmaps (Grad-CAM)
```bash
python src/explainability.py --image path/to/sample.jpg --checkpoint checkpoints/best_model.pth
```
